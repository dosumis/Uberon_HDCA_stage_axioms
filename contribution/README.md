# Proposed: taxon-scoped developmental stage axioms for Uberon

Generated by `make contribute`. Two files:

- `uberon-human-stage-gcis.ofn` — the axioms, OWL functional syntax
- `review.tsv` — the same claims as a table, one row each, with the evidence
  quote beside the claim it supports

**33 axioms over 33 structures**, all start bounds. Every one carries the
passage it rests on, from O'Rahilly & Müller, *Developmental Stages in Human
Embryos* (Carnegie Institution of Washington Publication 637, 1987) — the
reference the Carnegie staging system is defined by. The `support` column
distinguishes the 29 where a passage describes the structure at that stage from
the 4 argued from its absence at an earlier one.

141 further claims are **withheld**: 116 unsourced, and 25 where a source was
read for the term but no passage bears on the particular claim. The latter are
mostly end bounds — the evidence store records *start*, *present* and *absent*
observations and nothing recording an **end** — so end bounds will follow as a
second batch once the source is read for them.

## The pattern

```
(X and in_taxon some NCBITaxon:9606)
    SubClassOf existence_starts_during some HsapDv:nnnnnnn
```

A GCI rather than an assertion on `X` itself, because `X SubClassOf
existence_starts_during some 'Carnegie stage 09'` is an all-some claim — it says
every X in every organism starts at CS9, and Carnegie stages are human. The
taxon conjunct is what makes the claim sayable at all.

## Choice of predicate

`existence starts during` (RO:0002488) where the structure has a nameable onset;
`existence starts during or after` (RO:0002496) where it appears progressively
and a point claim would be false rather than merely imprecise — somites, the
pharyngeal arches and arch arteries, neural crest, the generic limb bud.

The distinction matters because Uberon's existing bounds are dominated by the
loose form against species-neutral stages, where it carries very little: 3348
terms assert `starts during or after gastrula stage`, which is true of almost
everything. A point claim against a Carnegie stage can be wrong, and therefore
checked.

## Why this does not materialise on its own

A GCI has no named subject, so relation-graph has nothing to attach an edge to
and the axiom produces no triples. We work around that locally by generating a
named class equivalent to each GCI's left-hand side, which is a build step
rather than an ontology change — see `sparql/expand.ru` in this repository.

Measured on uberon-base merged with 16432 such classes: relation-graph runs in
17 seconds, and the full table (these 33 plus the withheld claims) gives 324
Uberon terms an HsapDv bound — 211 of them inherited through `subClassOf` from a
term we never touched.

If Uberon would rather carry named human-scoped classes than GCIs, that changes
the contribution but not the content.

## One thing to be aware of

Scoped classes are generated for every Uberon class, including ones that cannot
exist in human. `Weberian vertebra and in_taxon some Homo sapiens` is an empty
class, so a bound on it is vacuously true — logically harmless, practically
noise. Filtering the generated classes by Uberon's own `only_in_taxon` /
`never_in_taxon` constraints would remove it; we have not done that yet.

## Checks run

- Every CURIE resolves, and every label in the table matches the ontology's.
- Predicate agrees with the curator's onset judgement (point vs interval).
- Stage ontology agrees with the taxon.
- No structure carries both an exact and a loose bound of the same direction.
- Round trip: table → OWL → expand → materialise → extract returns exactly the
  rows it started from.
